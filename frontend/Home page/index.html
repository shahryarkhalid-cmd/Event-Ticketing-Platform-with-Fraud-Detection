About Tixora

Built by four classmates tired of ticketing fees, app downloads, and scalpers.

Tixora started as a class project between four computer science students who'd all had the same bad night out: a $12 "convenience fee," a forced app download for a single concert, and a resale price triple the face value. We built the platform we wished existed — one that runs entirely in a browser tab, charges organizers fairly, and makes a resold, screenshotted ticket worthless at the gate.
